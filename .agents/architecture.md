# 架构约束

- `lark_event_gateway.cjs` 维护唯一飞书 WebSocket 连接并转发消息、卡片回调；不得恢复多个消费者竞争事件。
- `lark_claude_bridge.py` 负责事件规范化、任务/会话生命周期、Claude stream-json 解析和飞书卡片编排。
- 纯解析、命令构建、分页和状态转换保持为可单测函数；子进程、网络、文件和线程留在边界类。
- 同一任务复用会话与进度卡，普通飞书消息创建新任务，卡片输入继续原任务。
- 任务、卡片和 Claude session 标识的映射必须稳定持久化，重启后可恢复且不串任务。
- 修改共享状态前检查线程同步与停止路径，避免回调、刷新线程和生成线程竞态。
