# 集成规范

- 飞书事件字段视为不可信输入，统一通过规范化函数处理文本、富文本、媒体、引用和卡片回调。
- 同一条 WebSocket 连接同时注册消息与卡片事件，避免多消费者漏注册或争抢事件。
- Claude stream-json 解析必须容忍未知事件、增量 token、工具状态和异常结束，未知字段不得导致会话崩溃。
- 飞书卡片更新遵守 streaming 生命周期；生成中只更新当前轮，完成后再恢复分页历史。
- 外部 CLI 调用使用参数数组，检查退出码、stdout/stderr 和超时，不用未引用字符串拼 shell 命令。
- 重试必须有上限并保持幂等；发送、更新或完成卡片失败时避免创建重复任务或重复回答卡。
