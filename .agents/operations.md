# 运维规范

- `install-launch-agent.sh` 更新运行副本时保留任务状态和日志，不覆盖运行目录中的本机 `.env`。
- LaunchAgent plist 不展开写入 secret；`.env` 权限保持 `0600`。
- 后台服务使用 `run.sh` 统一加载环境与启动依赖，源码和安装副本的行为保持一致。
- 日志应包含任务与阶段标识，但不得记录 App Secret、token、完整凭据或敏感附件内容。
- 升级脚本必须支持重复运行；安装中途失败不能留下半写 plist 或破坏现有可运行副本。
- 修改启动或安装逻辑后运行 shell 语法检查，并在文档中同步真实操作方式。
